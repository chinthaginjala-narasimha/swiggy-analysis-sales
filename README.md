🎯 Project Overview

This project explores Swiggy food-ordering data to understand sales performance, customer ratings, food category trends, and geographical patterns.
Using Python and its data analysis libraries, I performed data exploration, cleaning, KPI analysis, and visualization to transform raw data into meaningful business insights.

🎯 Business Objectives

Analyze monthly sales and ordering trends.

Evaluate food category performance.

Examine customer ratings and ordering patterns.

Compare revenue across states and cities.

Identify the top 5 cities based on the selected sales metric.

Communicate findings through clear, data-driven visualizations.
